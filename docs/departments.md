# For departments

The units can be used as course content: for example as the practical
component of a numerical analysis course, or in a research methods course for
final-year and MSc students. The material is licensed under CC BY 4.0, so you
may adapt it, translate it and include it in your own course notes.

## A six-week practical with unit A1

A suggested allocation is one session of two to three hours per week, in a
computer laboratory or on students' own laptops. This outline has not yet
been tested in a class; adjust it to students' background and your timetable.
Introduce the corresponding theory before or alongside each practical.

| Week | Topic | Tutorial sections | Outcome |
|---|---|---|---|
| 1 | Setting up; the initial value problem | 0, 1 | Python working; first report |
| 2 | Euler's method; measuring convergence order | 2, 3 | Euler passes all gates |
| 3 | Heun's method and classical RK4 | 4 | All three methods pass |
| 4 | Comparing methods by cost | 5 | Error–cost plot interpreted |
| 5 | Stability and stiffness | 6 | Stability limits explained |
| 6 | Project brief and report | 7, 8 | Short written report with the verification report attached |

Unit A2 (iterative methods for linear systems) has the same nine-section
structure and can be used independently in a linear algebra or numerical
methods course. A1 is not a prerequisite for A2. For either unit, select
tutorial exercises for coursework; a complete project brief needs additional
time and supervision.

**Assessment:** the unit's [marking rubric](units/ode-ivp/supervisors/rubric.md)
can be adapted for coursework; a short viva in week 6 confirms that each
student understands their own code.

**Requirements:** the unit-specific mathematics, basic Python and NumPy,
and a computer with Python, NumPy, SciPy and Matplotlib installed. Trial the
setup on the computers students will actually use. The code and generated
reports run offline after installation; for formatted offline tutorials, save
the web sections as PDFs. See [getting started](getting-started.md).

## Curriculum connection

NUC's [Computing CCMAS](https://www.nuc.edu.ng/wp-content/uploads/2026/03/Computing-CCMAS-2023-FINAL.pdf)
includes error analysis, linear systems and ODE initial-value problems in
Introduction to Numerical Analysis (printed pages 105–106). A1 and A2 can
support practical work on those topics. Match the exercises to your own
programme's learning outcomes and assessment requirements.

verifiedmethods is independent and is not affiliated with or endorsed by NUC.
The units are optional teaching resources, not an accreditation or research
certification scheme.
